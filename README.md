# Stride

A personal marathon training dashboard that replaces Strava's paid analytics — heatmaps, training load, route hotspots — with a self-hosted app built on your own data.

---

## What it does

- Pulls every run from Strava automatically via webhook
- Enriches each run with weather data (Open-Meteo) and city name (Mapbox geocoding)
- Displays a training calendar, weekly mileage chart, and per-run stats
- Computes CTL/ATL/TSB training load (coming in M4)
- Surfaces AI coaching insights via Claude (coming in M5)
